## 🚀 Proyectos

- 🌦️ Virtual Wardrobe Weather  
  Proyecto full-stack que recomienda qué ropa ponerse según la ropa disponible del usuario, el tiempo, la fecha, la hora y la ubicación.

- 🍔 BurgerHub  
  Aplicación web con HTML, CSS y JavaScript para gestionar y mostrar menús de hamburguesas.

- 🐢 Modelo 3D de Squirtle  
  Modelado y renderizado 3D aplicando transformaciones, iluminación y técnicas básicas de renderizado (Informática Gráfica y Visualización).

  Sitio web adaptable con HTML, CSS y JavaScript para mostrar mis proyectos y habilidades.

  Matriz LED programable con Arduino, teclado matricial 4x4 y comunicación Wi‑Fi mediante ESP8266.
